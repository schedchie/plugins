# Security

This repository holds configuration files, an agent skill, setup steps and logo files. Nothing in it installs a package or runs anything by itself, and none of it holds a key. Every configuration points at one address, `https://mcp.schedchie.com/mcp`, and the sign-in is OAuth in your browser on schedchie.com.

## Reporting a security issue

Mail support@schedchie.com with "Security" in the subject line. Please do not open a public issue for a security report. Say what you found, where (a file in this repository, the MCP server at mcp.schedchie.com, or www.schedchie.com) and how to reproduce it.

## Before you install

- The only server address is `https://mcp.schedchie.com/mcp`. A copy of these files that points anywhere else, asks for your password, or asks for a token you did not create yourself in the Schedchie dashboard, did not come from Schedchie.
- Schedchie never asks for your password in a chat or a configuration file. Sign in only on the schedchie.com page your browser opens.
- On that page you choose the permission groups the connection gets. The assistant can use only the tools in the groups you ticked.
